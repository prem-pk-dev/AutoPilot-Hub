IMPORTANT · BRANCH ACTIVATION

Why the Run button is not embedded here

This is a static public website. It cannot safely hold a GitHub token to dispatch private actions. GitHub also requires a workflow_dispatch file to exist on the repository's default branch before the workflow can be dispatched from the Actions UI. The cloud runner is currently on the Phase 5 development branch, so it is not yet an active production control.

  1. Review and merge the Phase 5 pull request into the development branch.
  2. When you approve moving the cloud runner to the default branch, GitHub Actions will expose its manual dispatch controls.
  3. Use the workflow ID autopilot-hub-repo-health and download the generated report artifact.

Schedule configuration

No recurring task is enabled by default.

Daily / weekly schedules

A schedule can be added to the GitHub Actions YAML after the manual cloud runner has been validated and the desired frequency and timezone are confirmed. GitHub cron uses UTC, can start late, and is subject to free-tier usage limits. Browser-local tasks still require the tab to remain open.
